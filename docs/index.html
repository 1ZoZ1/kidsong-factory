03 / THE PRODUCTION SYSTEM

From a teaching idea
to a finished package.

A specialized, recoverable workflow connects the creative steps. Local FFmpeg composition brings the pieces together.

01

Imagine the lesson.

A creative brief defines the teaching goal, lyrics, cast, scenes and shot list.

Anthropic adapter
02

Build the world.

Reference-conditioned scenes become short loops, with a local motion fallback.

Ideogram · fal / LTX · FFmpeg
03

Find the song.

Generate the audio, align lyrics when possible, then plan cuts against the real duration.

Suno adapter · ElevenLabs Music
04

Compose & review.

Render the landscape video, lyric overlay, thumbnail and metadata. Watch it before publishing.

FFmpeg · local QA

The actual run order builds scenes before music: brief → scenes → motion → thumbnail → song → alignment → storyboard → render → metadata → QA.
